Java 环境管家

双击 D:\code\Java\JavaManager\JavaManager.exe 使用，不需要记命令。程序不依赖 Java 本身启动，使用 Windows 自带的 .NET Framework。

目前日常默认已设为 D:\code\Java\JDK8u451，完整版本为 1.8.0_451-b10。现有五套 JDK 和三个独立 JRE 均保留。

切换 Java

在“Java 版本”页选中版本，点击“设为日常默认”。新打开的终端和程序会使用新默认；已经打开的终端、IDE 和 Java 程序不会自动改变。若当前终端仍显示旧版本，请关闭后重新打开；长期运行的 IDE / 启动器可能需要重启。

点击“打开 CMD”或“打开 PowerShell”，会打开只使用所选 JDK 的独立终端。不同终端可以同时使用不同版本。打开终端时不会加载 PowerShell 配置或 CMD AutoRun，以减少版本被覆盖的情况。

每道 CTF 题固定完整版本

1. 打开“CTF 题目固定版本”页，选择题目文件夹。
2. 选择完整 JDK，例如 JDK8u65 / 1.8.0_65-b17。
3. 如需 JVM 参数，可每行填写一个；不需要时留空。
4. 点击“保存题目绑定”。文件夹会生成 .java-version 和 .java-runtime.json。
5. 以后从“最近打开的题目”选择该题，再点击“题目 CMD”“题目 PowerShell”或“用绑定版本运行 JAR”。

绑定记录完整构建号、厂商、绝对目录和核心运行文件 SHA-256。每次打开题目终端或运行绑定 JAR 前都会验证；JDK 被替换、删除或记录不一致时会报错，不自动退回其他版本。修改绑定文件不会自动执行其中的程序。JVM 参数只在点击运行 JAR 时应用，打开的终端不注入全局 JVM 参数。

题目目录中的绑定文件本身不会改变从其他位置启动的终端或 IDE。IDEA 的 Project SDK、运行配置、Maven Runner 和 Gradle JVM 需要手动选择同一个 JDK。已经打开的题目终端始终保持打开时的版本；若修改绑定，请重新打开题目终端。

绑定保证此工具的版本选择一致，不保证利用链一定成功。依赖库、题目服务、启动参数、操作系统和网络环境仍按题目说明准备。

运行 JAR

在“运行 JAR”页选择 JAR，可直接拖入文件。勾选“使用 CTF 题目页已保存的绑定”时，使用该题目绑定的 JDK、JVM 参数和工作目录；否则使用下拉框中选择的 JDK，工作目录为 JAR 所在文件夹。

JVM 参数和程序参数均每行一个，不额外加外层引号。输出显示在界面中，同时保存到 data\logs。若程序需要控制台输入，请在题目终端中运行。点击“停止本次运行”会终止本次 Java 进程；程序自行启动的其他子进程可能仍然存在。

JavaFX

当前 Oracle JDK8u65 和 JDK8u181 自带 JavaFX；JDK8u451、JDK17、JDK21 未带 JavaFX。遇到缺少 javafx 的工具，应按工具要求选择带 JavaFX 的版本，或另配匹配版本的 JavaFX。不能仅凭字节码识别 CTF 题目需要哪个 Java 8 更新号，所以本工具不擅自替换版本。

文件与恢复

- 主程序：JavaManager.exe
- 可重新编译的 C# 源码及编译脚本：source\
- 默认版本及最近题目：data\settings.json
- 环境变量与题目绑定修改前备份：data\backups\
- 首次清理系统 Java Path 前备份：C:\ProgramData\JavaManager\backups\

首次设置默认版本时，若系统 Path 有 Oracle Java 冲突入口，程序会通过 Windows 管理员确认清理这些 Java 入口。其他开发工具路径保留。之后切换现有 JDK 一般无需管理员权限。

保留源码、备份和数据目录。移动程序目录不会移动 JDK，已绑定题目中的 JDK 目录仍需有效。软件不会自动安装、升级或删除 JDK，也不改变 JAR 双击关联。
