# 验证范围

两套程序最初在 Windows 11 x64 上使用系统 .NET Framework C# 编译器构建并检查界面。仓库发布前会重新编译两套 EXE、验证图标、检查可分发 ZIP 的内容与 SHA-256。编译不执行环境切换操作。

## 已完成的本机集成验证

Java：8u65-b17、8u181-b13、8u451-b10、17.0.20.1+1-LTS-4、21.0.12.1+1-LTS-4。验证了编译、打包、运行、Maven 跟随、中文目录和特殊参数传递，以及绑定指纹与版本记录不一致时拒绝启动。测试源码见 `tests/JavaManagerTests.cs`。

Python：2.7.18、3.9.13、3.14.10，均为 64 位。验证了中文与空格路径下创建题目环境、离线安装本地测试 wheel、不同题目使用不同包版本、脚本参数传递、用户级包与覆盖变量隔离、基础 Python 包保持不变，以及解释器指纹或依赖快照变化时拒绝启动。测试源码见 `tests/PythonManagerTests.cs`。

这些测试依赖本机实际安装的解释器路径和版本，不能作为任意机器上的自动测试。测试会在测试程序目录下创建独立目录和虚拟环境，不应在用户题目目录中执行。仓库未包含测试运行时产生的用户目录、环境变量或完整日志。

## 限制

- 管家创建的子进程环境独立；已经打开的终端和 IDE 不会因默认切换自动更新。
- Java 目录根路径仍固定；Python 可以额外注册解释器，但创建 Python 2 环境的宿主路径仍约定为 `D:\code\Python\Python39`。
- Python 包清单基于 `pip freeze --all`，可记录版本和直接来源，但不对全部第三方包文件计算指纹，不等同于完整依赖哈希锁定。
- 虚拟环境使用绝对路径，不能直接移动后继续使用；基础解释器也需保留。
- 控制台交互程序应从独立终端运行。界面中的“停止”终止本次进程，不保证关闭其自行启动的子进程。
- JAR / 脚本自身、依赖库和原生扩展的兼容性仍由项目决定，不保证所有 CTF 题目或工具均可运行。
